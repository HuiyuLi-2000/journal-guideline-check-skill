# Cross-Check: Common Desk-Rejection Categories

**Scope**: only for the coverage cross-check at the end of Phase 1. These categories are not check items. After extracting the guideline's requirements, work backwards through this list to see whether the guideline touches each category.

- Guideline covers it → use the extracted clause
- Guideline says nothing about it → list it in the report as "⚠️ Not mentioned in the guideline", prompting the user to check (suggest the journal's submission system or the editorial office), **without judging the manuscript non-compliant**

## Categories

1. **Length limits**: full-text word / page caps (mind the basis: with or without references and appendices)
2. **Document structure**: required sections (abstract / keywords / highlights / declarations), section order, numbering style
3. **Title page**: title length, author and affiliation format, corresponding author marker, running head
4. **Abstract**: word cap, whether a structured abstract is required (and the specified subsection headings)
5. **Keywords**: count range, format (separators, alphabetical order)
6. **Body layout**: line spacing, font and size, margins, single vs double column, page and line numbers
7. **References**: citation style (APA / Vancouver / the journal's own), count cap, in-text citation format
8. **Figures and tables**: count cap, resolution and file formats, caption and numbering rules, embedded in text or collected at the end
9. **Anonymization**: single- or double-blind (author details, acknowledgements, funding disclosure, self-citation phrasing)
10. **Declarations**: conflict of interest, ethics statement, data availability, author contributions (CRediT)
11. **Submission materials**: cover letter, highlights, supplementary files
12. **Submission rules**: file format (Word / LaTeX / PDF), filename conventions, submission-system specifics

## Typical Figures (for a sense of scale in notes only; every threshold used in a judgment must come from the guideline's own wording)

- Abstract caps often 150–300 words; keywords often 3–8
- Double-blind journals usually require a separate title page, de-identified body text, and third-person self-citation
- Figure resolution is often ≥ 300 dpi (photographs) / ≥ 600 dpi (line art)
